Title: cron: split the job `script` field into path + arguments

`_run_job_script` treats the whole `script` string as a filename, so a job
whose `script` is `"cleanup.py --days 30"` fails with file-not-found — there
is no way to pass arguments to a cron job script. This splits with
`shlex.split()` (quoting-safe) and appends the remaining tokens to the argv
for both the python and bash branches.

Backward compatible: a bare path splits to itself; paths with spaces keep
working when quoted (`"my dir/script.py" --flag`).

Running in production on a 75-job deployment since 2026-06; every
args-bearing job depends on it.
