# Synthesis-Generated Queue Item Classification

## The Problem

Queue items generated by synthesis workers use the format:
```
[NEW from synthesis v484] Confidence-gated fusion recovers 42% of hybrid failures — can we build a meta-learner...
```

These items lack `exp_XXX` source IDs. The standard classification regex `re.findall(r'exp_(\d+\w*)', text)` returns empty, so all such items classify as NO_SOURCE — even when a running experiment covers the same topic.

## Impact (Cycle #259)

All 14 active queue items showed NO_SOURCE because they came from synthesis v481-v484. Manual topic-matching against running experiment titles was required to identify the 6 genuinely uncovered items out of 14.

Of the 14 items:
- 6 were covered by running experiments (GraalPy, INT1, routing+ensemble, XGBoost, cross-domain ceiling)
- 8 were genuinely uncovered
- Standard classification said all 14 were NO_SOURCE

## Mitigation: Two-Pass Classification

After the standard regex-based classification, run a second pass on NO_SOURCE items:

```python
import re
from collections import defaultdict

# Step 1: Standard classification (existing code)
# ... produces NO_SOURCE items list

# Step 2: Topic-matching against running experiments
running_titles = ' '.join(t.get('title', '').lower() for t in running)

for i, item in enumerate(no_source_items):
    text = item.get('text', str(item)) if isinstance(item, dict) else str(item)
    # Extract meaningful keywords (skip common words, experiment IDs, synthesis refs)
    stop = {'the', 'a', 'an', 'is', 'are', 'was', 'were', 'be', 'been', 'being',
            'have', 'has', 'had', 'do', 'does', 'did', 'will', 'would', 'could',
            'should', 'may', 'might', 'can', 'this', 'that', 'it', 'of', 'in',
            'to', 'for', 'with', 'on', 'at', 'by', 'from', 'as', 'what', 'how',
            'why', 'not', 'or', 'and', 'but', 'if', 'then', 'than', 'when',
            'which', 'who', 'we', 'you', 'they', 'new', 'synthesis'}
    words = set(text.lower().split())
    keywords = {w for w in words - stop if len(w) > 3 and not re.match(r'^v\d+', w)}
    
    overlap = sum(1 for w in keywords if w in running_titles)
    coverage = overlap / max(len(keywords), 1)
    
    if coverage > 0.3:
        # Reclassify as RUNNING (covered by existing experiment)
        category = "RUNNING_COVERED"
    elif coverage > 0.15:
        category = "PARTIALLY_COVERED"
    else:
        category = "GENUINELY_UNCOVERED"
```

## Decision Rules

| Category | Action |
|---|---|
| RUNNING_COVERED (coverage >0.3) | Skip — running experiment will resolve |
| PARTIALLY_COVERED (0.15-0.3) | Lower priority — may need follow-up after running experiment completes |
| GENUINELY_UNCOVERED (<0.15) | Create task — topic not addressed by any running experiment |

## Key Insight

As synthesis becomes the dominant source of queue items (rather than experiment follow-ups), the NO_SOURCE category grows while its usefulness as a "genuinely uncovered" signal degrades. The topic-matching second pass is essential for accurate classification.
